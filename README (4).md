# n8n AI Agent and Automation Workflows

n8n workflows and AI agents that remove manual work: finance reconciliation, lead qualification, customer support with RAG, voice agents, MCP tool calling and content automation.

Open a project folder to read its README: the business problem, the solution, how it works and a link to the workflow file.

| Project | Business problem solved | Key technologies |
|---|---|---|
| [Invoice Reconciliation Bot](./Invoice-Reconciliation-Bot) | Manual payment-to-invoice matching | n8n, JavaScript (Code node), Google Sheets, Gmail |
| [AI Lead Qualification Engine](./AI-Lead-Qualification-Engine) | Slow, manual lead triage | n8n, Groq (Llama 3.3), Google Sheets, Gmail |
| [RAG Email Support Agent](./RAG-Email-Support-Agent) | Slow, inconsistent support email replies | n8n, Google Gemini, Supabase vector store, Slack, Gmail |
| [RAG Messenger Support Agent](./RAG-Messenger-Support-Agent) | After-hours customer questions | n8n, Groq, Supabase pgvector, OpenAI Embeddings, Google Drive, Meta Graph API |
| [AI Voice Calling Agent](./AI-Voice-Calling-Agent) | Missed calls and manual appointment booking | Retell AI, Claude, RAG knowledge base, n8n |
| [MCP-Powered AI Travel Assistant](./MCP-AI-Travel-Assistant) | AI answers that need live data | n8n, Model Context Protocol (MCP), Apify, OpenAI |
| [YouTube Video Automation Pipeline](./YouTube-Video-Automation-Pipeline) | Time-consuming video production | n8n, OpenAI, Groq, Pixabay API, JSON2Video, YouTube API |
